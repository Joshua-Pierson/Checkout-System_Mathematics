# POS Checkout System

A unified, containerized Point of Sale system utilizing a Python/Flask backend, MySQL database, and Vite/JavaScript frontend. 

## Prerequisites
* [Docker Desktop](https://www.docker.com/products/docker-desktop/) installed and running.
* Git installed.

## Quick Start (Mac & Windows)

1. **Clone the Repository**
   ```bash
   git clone [https://github.com/Joshua-Pierson/Checkout-System_Mathematics.git](https://github.com/Joshua-Pierson/Checkout-System_Mathematics.git)
   cd Checkout-System_Mathematics
